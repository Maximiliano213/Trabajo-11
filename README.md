# 🏞️ Proyecto Web: Cerro Colorado - Turismo y Cultura

Este repositorio contiene los archivos fuente de un sitio web de turismo y cultura dedicado a **Cerro Colorado**, un importante patrimonio cultural y natural ubicado en la provincia de Córdoba, Argentina. El diseño es moderno y *responsive*, implementado con **HTML5** y **Bootstrap 5**.

---

## ✨ Características Principales

* **Diseño Moderno y Fijo:** El menú de navegación es claro (`bg-white`), tiene una sombra sutil y es **fijo** en la parte superior (`sticky-top`).
* **Call-to-Action (CTA):** El enlace de contacto se ha transformado en un botón primario destacado (`btn btn-primary`).
* **Estilo Temático:** Se utiliza una paleta de colores basada en tonalidades **rojizas y terrosas** (Terracota y Ocre) en el CSS para reflejar los colores del cerro.
* **Estructura Completa:** Incluye secciones clave como Carrusel, Historia, Lugares de Interés (usando Cards), Galería Multimedia y un formulario de Contacto.

---

## 📂 Estructura del Repositorio

| Archivo/Carpeta | Contenido |
| :--- | :--- |
| `index.html` | La página principal que contiene toda la estructura y el contenido del sitio web. |
| `styles.css` | Define la apariencia visual del sitio, utilizando variables CSS para colores y mejorando los estilos de Bootstrap. |
| `script.js` | Contiene lógica básica de JavaScript (actualmente solo un mensaje de consola). |
| `img/` | Carpeta para almacenar todas las imágenes (slides, tarjetas, historia, etc.). |
| `audio/` | Carpeta para el archivo `musica.mp3` referenciado en la galería. |
| `video/` | Carpeta para el archivo `turismo.mp4` referenciado en la galería. |
